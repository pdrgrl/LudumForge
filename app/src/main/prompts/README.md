# AI Prompts for LudumForge 🧠✨

This directory contains specialized prompts to be used with AI agents (Gemini, Copilot, etc.) during the development of LudumForge.

## 📁 Structure
- **`architecture_prompts.md`:** Structural changes, Hilt injection, and Layered logic.
- **`compose_prompts.md`:** UI development, Material 3, and Animation.
- **`debugging_prompts.md`:** Fixing logic errors or UI glitches.
- **`refactoring_prompts.md`:** Cleaning up code and following Clean Architecture.

## 📖 How to Use
1. Identify the task type.
2. Open the corresponding `.md` file.
3. Copy the base prompt.
4. Replace the placeholders (e.g., `{FeatureName}`) with your specific context.
5. Provide the prompt to your AI agent.
