# 03. User Stories: LudumForge

### 🏆 Core Experience
- **As a Solo Developer,** I want to generate a task list from my idea so that I don't waste time planning during a 48h jam.
- **As a Team Lead,** I want to assign tasks to my artists and programmers so that everyone knows their responsibilities.
- **As a Jammer,** I want to see a countdown timer so that I can manage my remaining time effectively.

### 🛠️ Task & Roadmap Management
- **As a User,** I want to edit a generated task because the IA might have overestimated a specific mechanic.
- **As an Artist,** I want to filter the roadmap to see only "Art" tasks so that I can focus on my work.
- **As a Developer,** I want to mark a task as "Done" so that the progress bar updates for the whole team.

### 🚨 Emergency & Survival
- **As a stressed Developer,** I want to press the "Panic Button" 5 hours before the deadline so that I know what is absolutely essential to finish.
- **As a User,** I want the app to warn me if my current progress is slower than the initial roadmap estimate.

### 🌐 Connectivity & Collaboration
- **As a Team Member,** I want to see real-time updates when my partner finishes a task so that we don't duplicate work.
- **As a User,** I want to use the app in a train with no Wi-Fi so that I can still check my design notes and tasks.
- **As a User,** I want to find a theme and team for an upcoming jam in "The Arcade" so that I can prepare in advance.

### 👤 Profile & Subscription
- **As a Free User,** I want to manage at least 2 team projects per month so that I can participate in major jams.
- **As a Premium User,** I want unlimited projects and advanced productivity stats so that I can improve my performance over time.
